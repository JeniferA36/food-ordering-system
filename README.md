# Food Ordering System

An online food ordering website where users can browse restaurants and order food easily.

## Features
- User can register, login and order food
- Admin can add restaurants and manage orders
- Cart functionality and order tracking
- Responsive design with images for food items

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Java Spring Boot
- Database: MySQL

## How to Run
1. Clone this repo: git clone https://github.com/JeniferA36/food-ordering-system.git
2. Open in IDE (Eclipse / IntelliJ / VS Code)
3. Configure MySQL in application.properties
4. Run the application
